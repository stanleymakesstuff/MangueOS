##############################################################################
#  MANGUE OS - FIRST-BOOT SETUP FILE
##############################################################################
#
#  What is this file?
#    This file sets up your MangoPi the first time it starts, so you never need
#    a screen or keyboard ("headless"). You fill it in on your PC, put the card
#    back in the board, and power it on. The board reads this file at start-up.
#
#  How to use it:
#    1. Open this file with Notepad (Windows), TextEdit (Mac) or any text editor.
#    2. Type your choices after the = signs below. No quotes needed.
#    3. For timezone, locale and Wi-Fi country: delete the # at the start of
#       ONE line to choose it ("uncomment" it). Leave the other lines alone.
#    4. Save the file, eject the card safely, put it in the MangoPi, power on.
#    5. Wait 3-5 minutes for the first start. Then connect (see the end of
#       this file).
#
#  Good to know:
#    - Lines starting with # are notes; the board ignores them.
#    - Your passwords are ERASED from this file once they are used, so they
#      do not stay readable on the card. They keep working.
#    - To change something later (a new password, another Wi-Fi, a new user):
#      edit this file on your PC and start the board with it. The board applies
#      only what you changed, erases the passwords again, and lists what it did
#      in mangue-setup-result.txt. A new username + password ADDS a user; the
#      old one is kept. Anyone who can edit this card can do this - keep it safe.
#    - What happened is written to mangue-setup-result.txt next to this file.
#      If something did not work, put the card in your PC and read it.
#    - While it runs, the board keeps mangue-status.txt up to date next to this
#      file: its address, whether setup finished, and how to connect.
#    - Windows may say "You need to format the disk in drive X:" when you put
#      the card in. That is the board's Linux part, which Windows cannot read.
#      Click CANCEL. Never format it.
#    - If you leave username/password empty, nothing is set up automatically;
#      you then set up on a screen + keyboard or a serial cable instead.
#
##############################################################################
